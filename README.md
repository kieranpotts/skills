# Skills for AI agents

This repository captures a curated collection of skills, rules, instructions, and custom prompts for use by AI tools.

Each skill is written for token-efficiency and includes:

- Clear purpose and use cases.
- Step-by-step instructions.
- Practical examples and edge cases.
- Technical references and domain-specific notes.

[Browse the skills here.](./skills/)

## Creating skills

To create a new skill, use the template in `template/skill-name/` as a starting point.

Each skill requires, as a minimum, a `SKILL.md` file that defines:

- Metadata (name and description are REQUIRED, compatibility and license etc. are OPTIONAL).
- Instructions for applying the skill.
- Examples and edge cases.
- References and supporting documentation.
