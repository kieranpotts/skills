# Skills for AI agents

A curated collection of skills, rules, instructions, and custom prompts for use by AI tools.

## Overview

This project organizes knowledge into skill modules across several domains:

- **Chat**: Conversational and communication-focused skills.
- **Code**: Coding conventions for various programming languages.
- **Docs**: Documentation and technical writing.
- **Plan**: Planning, architecture, and project management.
- **Product**: Product development and strategy.
- **Standards**: Best practices and standards.
- **Tools**: Working with development and operations tools and services.
- **Utils**: Working with single-purpose system tools: `git`, `jq`, etc.

Each skill includes:

- Clear purpose and use cases.
- Step-by-step instructions.
- Practical examples and edge cases.
- Technical references and domain-specific notes.

## Getting started

To create a new skill, use the template in `template/skill-name/` as a starting point. Each skill requires, as a minimum, a `SKILL.md` file that defines:

- Metadata (name and description are REQUIRED, compatibility and license etc. are OPTIONAL).
- Instructions for applying the skill.
- Examples and edge cases.
- References and supporting documentation.
