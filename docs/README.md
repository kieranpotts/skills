# 🛠️ Developer documentation

This documentation is for the maintainers of this code repository, which is not
open for external contributions. For usage docs, refer to the [project
README](../README.md).

See also [TS-61: AI Tools](https://kieranpotts.com/standards/061).
It is the technical standard that underpins these agent skills. TS-61 covers the
broad design principles and best practices for agentic software development,
which have been influential in the design of this collection of agent skills.
