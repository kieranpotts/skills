# Objectives

The overriding objective in the design of an agentic workflow is to produce **predictable outcomes**, and for those outcomes to be highly **consistent** across all mainstream coding models.

To achieve predictable, consistent outcomes, you need to base your agentic workflows on concrete, verifiable [success criteria](./success-criteria.md). This means giving agents clear, self-verifiable criteria for what "done" and "correct" look like.
