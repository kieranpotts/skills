# Skills

The capitalized words REQUIRED, MUST, MUST NOT, RECOMMENDED, SHOULD, SHOULD NOT,
OPTIONAL, and MAY are to be interpreted as described in
[IETF RFC 2119](https://www.ietf.org/rfc/rfc2119.txt).

## Project overview

This is a curated collection of agent skills for AI-assisted and agentic
software development. The skills encode established development practices,
SDLC phases, and version control conventions, into reliable prompts. These
prompts are designed to produce consistent, predictable outputs across
mainstream coding models.

Each skill is portable and independent. No skill hands off to another skill.
You can install or delete any one skill on its own, and orchestrate them into
all sorts of workflows.

Every `SKILL.md` file SHOULD be token-efficient (RECOMMENDED limit: 500 lines,
counting blank lines) and MUST pass the validator checks — described below.

## Tech stack

- **Bash** (installer and validator scripts).

- **`pre-commit`** (Python) for Git hooks.

- **`skills-ref`** (Python, OPTIONAL) for canonical `SKILL.md` validation.

- **GitHub Actions** for delivery pipelines.

## Project structure

- **`skills/`**. One subdirectory per skill, each containing a `SKILL.md`
  (for agents) and a `README.md` (for humans).

- **`skills/create-skill/`**. Use this to author new skills, both in this
  repository and in downstream projects. It bundles the canonical template
  (`assets/create-skill-template/`), the validator (`scripts/`), and reference
  docs (`references/`).

- **`build/`**. Compiled agent-specific artifacts generated by `./run/install`.
  Do not edit directly.

- **`run/`**. Dev tools. Just the `install` script, for now.

- **`docs/`**. Documentation for maintainers and contributors to this project.

- **`skills.sh.json`**. Controls how skills in this collection are presented on
  the [skills.sh](https://www.skills.sh/) website.

- **`CHANGELOG.md`**. Version history.

- **`CONTRIBUTING.md`**. Contributing guidelines for humans only.

## Tools

- **`./run/install --help`** to build and install skills into supported agents.

- **`./skills/create-skill/scripts/create-skill-validate.sh <skill_dir>`** to
  validate a skill directory before committing changes to it.

- **`pre-commit run --all-files`** for linting commit messages (requires
  `pipx install pre-commit && pre-commit install`).

## Rules

- MUST follow the [**branch**](./skills/branch/SKILL.md) skill for all branch
  names.

- MUST follow the [**commit**](./skills/commit/SKILL.md) skill for all commit
  messages.

- MUST NOT commit anything under `build/`. It is git-ignored, except for
  `build/README.md` which is tracked.

- MUST use the [**create-skill**](./skills/create-skill/SKILL.md) skill to
  create or modify a skill. See also [`docs/creating-skills.md`](./docs/creating-skills.md).

- MUST run the [create-skill validator](./skills/create-skill/scripts/create-skill-validate.sh )
  on any new or modified skill before committing the changes.

- MUST hard-wrap prose in Markdown files at 80 characters, except Leave unbroken
  anything that reads better as long lines, such as tables and long URLs. Never
  break a line inside a link, code span, or emphasis.

  working with Git. Covers commits, branching, merging, integration strategies,
