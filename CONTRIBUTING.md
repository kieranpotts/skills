# Contributing

<!-- Agents MUST read ./AGENTS.md. This document is for sapien. -->

This repository is closed for external contributions. The skills are closely
aligned with the author's own ways of working and are not intended for general
use.

You are, however, welcome to fork this repository and use these skills as a
baseline from which you can iterate your own agentic workflow — one that encodes
_your_ chosen methods and tools.
